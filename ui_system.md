# SIRAJ – UI System

---

## 🎨 Design Principles

* Minimal
* Clean spacing
* Dark theme (default)
* Blue gradient accents
* Focus on usability, not decoration

---

## 🧱 UI Library (MANDATORY)

Use a professional component library.

### Primary Library:

* shadcn/ui

---

## 📦 Requirements

* Use shadcn/ui components ONLY for base UI
* Do NOT build components from scratch unless necessary
* Use Tailwind CSS for styling

---

## Components to Use

From shadcn/ui:

* Button
* Input
* Label
* Select
* Textarea
* Card
* Table
* Badge
* Dialog (modals)
* DropdownMenu

---

## 🧩 Layout System

Main layout:

Sidebar | Main Content | Right Panel (optional AI panel)

---

## 📄 Pages

### 1. Dashboard

* Summary cards
* Recent RFQs
* Quick actions

---

### 2. RFQs List

* Table view
* Status badges
* Create button

---

### 3. RFQ Create

* Step-based form (wizard)
* Clean spacing
* No clutter

---

### 4. RFQ Detail

* RFQ info
* Invite links
* Response table

---

### 5. Public Form

* Simple centered layout
* Minimal distractions
* Clear submit button

---

## ⚠️ UI Rules

* No custom CSS unless necessary
* No complex animations
* No heavy gradients
* Use spacing, not borders
* Avoid visual noise

---

## 🚫 Anti-Patterns

* Building UI from scratch
* Inconsistent spacing
* Over-designed components
* Mixing multiple UI libraries

---

## 🎯 Goal

A clean, modern SaaS interface similar to:

* Linear
* Notion
* Stripe Dashboard
